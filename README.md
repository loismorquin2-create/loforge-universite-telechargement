# Loforge Université — téléchargement

**[→ Page de téléchargement](https://loismorquin2-create.github.io/loforge-universite-telechargement/)**

Transcription de cours magistraux pour étudiants. Le logiciel écrit le cours au
fil de la parole, le range par séance, et — avec Claude Code — en tire un cours
corrigé, une fiche de révision et des exercices.

## Installer

1. **[Télécharger l'installeur pour Windows](https://github.com/loismorquin2-create/loforge-universite-telechargement/releases/latest/download/LoforgeUniversite-installeur.exe)**
2. Windows affichera « Windows a protégé votre ordinateur » : clique sur
   **Informations complémentaires**, puis **Exécuter quand même**. Le logiciel
   n'est pas certifié auprès de Microsoft — ça coûte plusieurs centaines
   d'euros par an. Windows ne dit pas qu'il est dangereux, il dit qu'il ne sait
   pas qui l'a écrit.
3. Au premier lancement, l'application affiche un **code de poste**. Envoie-le à
   contact@loforge.fr pour recevoir ta clé.

[La notice complète](NOTICE-INSTALLATION.md) répond à tout le reste.

## Ce qu'il faut savoir avant d'installer

- La reconnaissance vocale passe par **Google** : pendant la séance, le son du
  micro y transite pour devenir du texte. **Aucun fichier audio n'est
  conservé**, nulle part.
- Une clé ne fonctionne que sur **l'ordinateur pour lequel elle a été faite**.
- Windows 10 ou 11, et Google Chrome.
